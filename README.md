# ✳ Pocket Breaks

Three small browser games for a good little break. Built by [Palani](https://github.com/Palanid-789), with AI-assisted development.

**[Play the collection](https://palanid-789.github.io/pocket-breaks/)**

| Game | Challenge | Implementation |
| --- | --- | --- |
| Perfect pairs | Match eight pairs with fewer moves | Shuffled deck, delayed reveal, restart-safe state |
| Lights out | Turn off a 5×5 light board | Solvable-by-construction boards and cross-neighbor toggles |
| Number trail | Find 1 through 25 in order | Monotonic timer with hidden-tab pause |

## Why I built it

A small exploration of interaction design, game state, and satisfying feedback. Each game has a single rule, keyboard-operable buttons, responsive layouts, reduced-motion support, and local personal bests.

## Run locally

Open `index.html`, or run `python3 -m http.server 8080` in this folder. No build step, dependencies, accounts, analytics, or external assets. Scores stay in browser localStorage.

## Add to Notion

Paste the play URL into Notion and choose **Embed**, or use `/embed` with the same URL. Use a frame at least 600px tall; on small frames the page scrolls. A standard bookmark also works if embedded previews are restricted.

## Project structure

- `index.html` — accessible page structure
- `style.css` — responsive visual design
- `game.js` — game logic and persistence

## Development notes

Lights Out boards are generated by legal moves from the solved board. Memory callbacks use a round identifier so restarting or changing games cannot apply an old timeout. Number Trail starts only on the first correct tap. Best scores are device-local and not suitable for competitive leaderboards.

## Contributing

Open an issue with reproduction steps, or a pull request with a focused change. For game changes, check restart, switching games during animations, keyboard input, narrow screens, and win conditions. No payments, tracking, or mandatory accounts, please.
